# Identidad visual · Vela · cuidado coordinado

> Propuesta inicial; si no convence, se cambia nombre y colores aquí y en `frontend/src/theme.ts`.

**Nombre:** Vela · cuidado coordinado. **Idea:** una vela acompaña, alumbra y se cuida entre varios.
**Tono:** cálido, claro, respetuoso; frases cortas; hablar de "personas mayores", nunca "abuelitos" ni "ancianos".

## Logotipo
`assets/brand/logo.svg` (completo) y `assets/brand/logo-mark.svg` (ícono, favicon).

## Colores
| Token | Hex | Uso |
|---|---|---|
| `teal` | `#0F5C6E` | Color principal, encabezados, botones |
| `coral` | `#E8704A` | Acento, llama del logo, llamados a la acción secundarios |
| `cream` | `#FAF7F2` | Fondo |
| `ink` | `#1F2A30` | Texto |
| `muted` | `#5B6870` | Texto secundario |
| `ok` | `#2E7D4F` | Estado correcto (siempre con texto) |
| `warn` | `#B7791F` | Atención |
| `danger` | `#C0392B` | Emergencia, crítico |

## Tipografía
Atkinson Hyperlegible (Google Fonts, licencia OFL), diseñada para baja visión.
Cuerpo 18 px, modo sencillo 24 px; títulos 28/22 px; interlineado 1.5.

## Componentes
Botones de al menos 48 px de alto con texto + ícono; tarjetas con bordes de 12 px de radio; estados con
ícono y palabra ("En camino", "Atrasada"), nunca solo color.
